Requirement categories

A second major, a minor, or any standalone compulsory block your faculty adds on its own — Computing Ethics, a language requirement. Each one becomes its own bucket.

Composition rules

For a bucket whose requirement is written as a mix — "12 units of CD/ID, at least 2 ID, at most 1 CD". Courses whose code starts with the tag are matched automatically.

Exemptions

Courses you have been excused from. The code counts as already taken for prerequisite checks; add units only if your faculty actually credits them.

Specialisations

A specialisation is a tag, not a bucket. Tag the programme electives you're already taking and they count in both places at once.

Park a slot now, swap in the real code when you pick it.
